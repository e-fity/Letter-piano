# pianoWeb — 字母谱网页生成器

把 `_review.json`（两阶段流程的产物，或页组合并出来的那一份）渲染成一个**自包含的
HTML 文件**：字母谱按原谱行排布、音区分色、减时线/附点/延时线/休止/小节线/反复记号/
括号/连音弧/歌词齐全，点击字母可以试听。

**它不改动原本的识别管线**——只**只读**用 `jianpu2letter` 的 `review_io`（读 JSON）
和 `mapping`（唱名→键位查表）。识别、渲染 PNG/XML 仍由原工具负责。

## 用法

```bash
python pianoWeb/build.py out/4_review.json -o pianoWeb/4.html
python pianoWeb/build.py out/演员_review.json -o pianoWeb/演员.html          # 页组合并出来的那份
python pianoWeb/build.py out/4_review.json -o pianoWeb/4.html \
       --annotations pianoWeb/4.notes.json                                    # 带分段/面板
```

输出是**单个 HTML**（CSS/JS/数据全内嵌），双击即可看，不需要服务器。

## 哪些自动、哪些要手填

| 内容 | 来源 |
|---|---|
| 字母、音区分色、减时线 `_`、附点 `·`、延时线 `—`、休止 `0`、小节线/反复/终止、括号、连音弧、歌词 | **自动**，全部来自 JSON 真数据 |
| 谱头（曲名 / 调号 / 拍号）、低置信标记（黄框） | **自动** |
| **分段名**（主歌/副歌/前奏…） | **手填**——工具不产出分段 |
| **注释面板**（音区校正 / 判读规则…） | **手填**——内容逐谱手写，无法自动生成 |
| 副标题 | 手填（可选） |

> 分段与面板放在**旁注 JSON**里，用 `--annotations` 指过去；**不填就整块不显示，不报错**。

## 旁注文件格式

见 `4.notes.json`（自带 `_说明` 字段，可直接照改）：

```json
{
  "subtitle": "（张明敏演唱）",
  "sections": [
    { "name": "主歌 × 2", "lines": [1, 2, 3, 4] },
    { "name": "副歌",     "lines": [5, 6, 7, 8] }
  ],
  "panels": [
    { "title": "音区校正", "html": "…（可以用 <b> 等少量标签）" }
  ]
}
```

- `sections[].lines` 用的是 `_review.json` 里的**行号**（`L01` → `1`）。
- 不写 `sections` 就按原谱 11 行平铺，没有分段标题。

## 读谱记号约定（本页的显示规则）

| 谱面显示 | 含义 |
|---|---|
| 蓝色字母 `Z-M` | 低音 |
| 琥珀字母 `S-K` | 中音 |
| 绿色字母 `E-Q` | 高音 |
| 字母左上角 `L⇧` / `R⇧` | 该音用左/右 Shift（映射2 的 ±2、±3 八度） |
| 字母下方横线 | 减时线（1/2/3 条 = 八/十六/三十二分音符） |
| 字母后 `·` | 附点 |
| 字母后 `—` | 延时线 |
| 灰色 `0` | 休止 |
| 灰掉的 `∅` | **已「去除」** ——该块不是音符，导出 JSON 里这条已被删掉（见下） |
| **红底 `Q`** | **没认出来**（`_review.json` 里 `n` 为 `null`）——就是工具在谱面上**画红框**的那一批。要人工核对后改 JSON 再重生成 |
| 字母上方的弧 | 连音弧（跨音；行末半截为跨行残段） |
| 字母外细框 | 该音**低置信**（`conf < 0.70`），对应工具产物里加黄底的那些 |

## 改错音（页内编辑）

**双击打开 HTML 就能改，不需要任何服务、不落任何盘在 `out/`。**

1. 点右上 **「校谱修改」** 进入校谱模式（再点一次退出）；
2. 点谱面上任意一个**字母** → 弹出「修改这个音符」：
   - 21 个字母键（Z-M 低 / S-K 中 / E-O 高）+ **`0` 休止** + **`∅` 去除** + **`Q` 认不出**；
   - **`∅` 去除**：这个块**根本不是音符**（升号 `♯`、间奏文字「（间奏略）」、汉字残片…）。
     保存后显示成灰掉的 `∅`，**不再发声、不进「复制字母谱」，并会从导出的 `_review.json`
     的 notes 里删掉** —— 下游重出成品时这个音连同它的时值一起消失（时值在 `review_io`
     里按 beams/dotted/extend 重算）。点「恢复原谱」可放回。
     > 例：36.jpg 的 `6 6 #5 6 7 7 3 2.`，`#` 被工具当成一个独立音符 → 该小节多一个音、
     > 后面全错位。把那个 `?` 标成「去除」后，该小节恢复成原谱的 8 个音。
   - **Shift 层级**（L⇧ / R⇧）——中音档、休止、去除都没有 Shift 层，会自动禁用；
   - 弹窗上方有「原谱 / 当前 / 时值线」，并写明*改音高不会动时值或 Shift 层级*；
   - **修改原因**选填，会进导出清单（就是"学习记录"）。
3. 保存后：**页面立刻更新**该音，被改过的音右上角有个小点；右上出现 **「导出改动 (N)」**。
4. 点「导出改动」下载**两份**：
   | 文件 | 用途 |
   |---|---|
   | `<曲名>_review.json` | **改好的完整审核 JSON** —— 拿它重出成品（**不重跑 OCR**）：<br>`python -m jianpu2letter 下载的_review.json -o out` |
   | `<曲名>.edits.json` | 改动清单：每个音的 `id` / 原值 / 新值 / 原因 —— 攒起来就是人工修正的**真值集** |

> ⚠ **注意**：重跑**图片**转换（`run_all.py` 或 `jianpu2letter piano/xxx.png`）会**整份覆盖**
> `out/<图>_review.json`，页面上的编辑就没了 —— 这是刻意的（见 CLI 里 `save_review` 那段）。
> 所以要留着的改动，请先「导出改动」把它存到你自己那边。
> 相反，"把改好的 JSON **喂回**"这条路（`python -m jianpu2letter xxx_review.json -o out`）**不会**覆盖 JSON。

## 改了页样式想重新生成

只改 `template.html`（CSS/JS 都在里面），然后重跑 `build.py` 即可——数据不重新识别。
